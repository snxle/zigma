getting started

what you need and how to get Zigma running.

requirements

  • Minecraft 1.21.4
  • Fabric Loader
  • Fabric API
  • Java 21

installation

  1. install Fabric Loader for 1.21.4
  2. grab the jar (`zigma-1.1.70.jar`) from the main page
  3. copy the jar to your mods/ folder
  4. start the game
no setup needed, settings save themselves. the menu opens with RIGHT CONTROL, you can change the key in client / ClickGui / Keybind.
